# Lê UAI – Protótipo de alta fidelidade

Protótipo navegável da **Lê UAI – Biblioteca Digital Inclusiva**, feito na Etapa 3 (Design de Interação) do projeto de Design Centrado no Usuário do curso de Sistemas de Informação da PUC Minas.

**Acesse:** https://carlosjfcosta.github.io/leuai-prototipo/

## Como usar

- Para entrar, qualquer e-mail e senha funcionam.
- A barra de acessibilidade fica no topo de todas as telas: fonte (100%, 115%, 130% e 150%), espaço entre linhas (normal ou ampliado), tipo de letra (sem serifa ou com serifa) e contraste (normal, alto ou baixo).
- Dá para usar só o teclado: Tab para andar, Enter para escolher e as setas ← e → para virar as páginas no leitor.
- Os dados ficam só no navegador. O botão **Reiniciar demonstração**, no rodapé, apaga tudo antes do próximo teste.

## Observações

- Dados fictícios para teste de usabilidade. As obras são de domínio público.
- Feito com HTML, CSS e JavaScript, sem bibliotecas.
- Fontes Atkinson Hyperlegible e Merriweather, com licença SIL Open Font License (os arquivos da licença estão na pasta `fontes`).
